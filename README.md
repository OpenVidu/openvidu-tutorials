# OpenVidu Tutorials

Tutorials to get started with [OpenVidu](https://openvidu.io). The source code for
every tutorial lives in this repository, in
[openvidu-livekit-tutorials](https://github.com/OpenVidu/openvidu-livekit-tutorials) or in [openvidu-meet-tutorials](https://github.com/OpenVidu/openvidu-meet-tutorials).

## OpenVidu Platform Tutorials

| Category | Description |
|---|---|
| [Introduction](https://openvidu.io/latest/docs/build-your-app/) | The four steps to build an OpenVidu application, and how the tutorials below fit into each one |
| [Server](https://openvidu.io/latest/docs/tutorials/application-server/) | Build the backend in Node.js, Java, Python, Go, .NET, PHP, Ruby or Rust |
| [Client](https://openvidu.io/latest/docs/tutorials/application-client/) | Build the frontend in React, Angular, Vue, JavaScript, Electron, Ionic, Android or iOS |
| [Advanced features](https://openvidu.io/latest/docs/tutorials/advanced-features/) | Recording to S3-compatible storage or Azure Blob Storage, and more |
| [Angular components](https://openvidu.io/latest/docs/tutorials/angular-components/) | Customize the video conferencing UI: layouts, toolbars, panels, chat, participant items and your own branding |
| [AI Services](https://openvidu.io/latest/docs/tutorials/ai-services/openvidu-live-captions/) | Real-time transcription and live captions using the OpenVidu Speech Processing agent |

## OpenVidu Meet Tutorials

[Embedding tutorials](https://openvidu.io/latest/meet/embedded/tutorials/) — working
sample applications that embed OpenVidu Meet into your own application.
